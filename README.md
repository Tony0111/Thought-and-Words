# Writing

个人写作系统：让 AI 辅助写作时，既保留自己的观点和素材，又能稳定地使用自己喜欢的表达方式。

这个仓库不是“让 AI 模仿某篇文章”，而是把写作拆成可复用的几个部分：

- **Skill**：规定 AI 怎么工作（先问什么、不做什么、怎么审稿）
- **风格档案**：可执行地描述你想要的语言特征，目前有两个目标风格（A 内省心理 / B 宏大激励）
- **参考文章库**：提供风格证据，提炼规律
- **素材与观点**：这篇文章真正要表达的内容，来自你自己
- **草稿与成稿**：从 brief 到发布的工作区

## 风格档案

| | A · Yino | B · Monolith |
|---|---|---|
| 题材 | 心理剖析、哲学随笔、个人心理叙事 | 科技/创业/时代、人物特稿、激励邀请 |
| 气质 | 平静、温柔、向内 | 宏大、笃定、向外 |
| 落点 | 人如何成为自己 | 为年轻人描绘值得投身的事业图景 |

选哪个：**向内写一个人的内心 → A；向外写时代与事业、号召行动 → B。**

## 快速开始

1. 读 `docs/workflow.md` 了解整体流程。
2. 往 `corpus/raw/<作者>/` 放 5–10 篇你最认可的文章。
3. 用 `tools/extract_wechat.py` 抽取正文，让 AI 分析并产出风格档案初稿。
4. **人工确认并修改**风格档案 —— 这一步不能省。
5. 之后用 `/skill:personal-writing` 开始写文章。

## 核心原则

- 内容来自你：经历、观察、观点、事实、判断。
- 表达可以借鉴：节奏、结构、语气、叙述方法、具体程度。
- 参考文章里的句子、意象和术语可以直接使用。
- 先提炼“风格特征”，再据此写新文章，而不是每次丢原文说“模仿这个”。

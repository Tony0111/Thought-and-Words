# 参考文章库

存放你欣赏的、用于提炼写作风格的文章。

## 用法

1. 把文章放进 `raw/`，格式为 `.md` 或 `.txt`，文件名用能认出来的标题。
2. 一次先放 **5–10 篇**，不要一上来放几十篇。
3. 让 AI 分析这些文章，把提炼结果写进
   `.agents/skills/personal-writing/references/favorite-examples.md`。
4. **人工确认**哪些特征是你真正想要的，再据此更新 `style-guide.md`。

## 原则

- 参考文章只用来学习：句子节奏、叙述视角、开头结尾方式、抽象程度、情绪距离。
- 参考文章里的句子、意象和标志性表达可以直接使用。
- 优先选“你希望自己写出来”的文章，而不是“很好但不像你”的文章。

## 分类（可选）

- `raw/` —— 原始文章
- `raw/notes/` —— 你对某篇文章的批注

## 分析提示词

让 AI 分析时，可以要求它按以下维度逐篇输出，再汇总：

1. 句子节奏与长度分布
2. 叙述视角与情绪距离
3. 开头方式
4. 论证 / 推进方式
5. 结尾方式
6. 抽象与具体的比例
7. 高频可迁移特征（3 条以内）
8. 标志性表达（术语、意象、句子）

最后汇总为：**所有文章的共同特征** 与 **互相矛盾的偏好**（矛盾的地方交给用户决定）。

# D · 毛泽东（唯物辩证法 · 冷静判断 · 领导者的力量）

> 语料目录：`corpus/raw/Mao/`，相对于项目根目录。本轮以《实践论》《矛盾论》《论持久战》《反对本本主义》《改造我们的学习》《反对党八股》等已阅读正文及相关选段为主要依据；目录共有 35 篇，不表示每篇均已通读。
> 方法与引文：[方法库](../mao-ideas.md)；篇章分析：[示例索引](../examples/mao.md)。
> 本档案是结合用户偏好的写作提炼，不是作者全部作品的统一画像，也不是对其所有历史判断的正确性背书。

## 0. 核心定位：力量不是腔调，是判断的结果

**以扎实的唯物辩证法分析现实，把判断的根据讲透，再以冷静、明确、负责的语言指出方向。**

用户明确偏好：哲学基础深，尤其是唯物辩证法；有领导者风范，冷静而有力量；力量建立在哲学判断和科学判断上。其余写法是可调整的编辑默认，不需要逐项等待确认。

这几个特点不是并列的装饰，而有内在联系：

**研究实际 → 辨认关系与矛盾 → 把握主次、阶段和变化条件 → 形成有根据的判断 → 明确行动与责任 → 在实践中修正。**

哲学决定怎样看问题；调查与论证决定判断能站到哪里；领导者的力量体现在作出取舍、承担后果。不是先摆出坚定的姿态，再寻找几句哲学名词替它撑腰。

## 1. 哲学基础要进入论证，不能停在术语上

### 1.1 唯物：从客观处境和实际关系出发

- 写一个人或群体的选择，先看其资源、劳动、利益、处境、制度约束及与他人的关系，不只解释成性格、意愿或观念。
- 不把愿望当事实，也不以抽象原则替代具体调查。《反对本本主义》说：
  > 一切结论产生于调查情况的末尾，而不是在它的先头。
- 亲身经验、可靠的间接资料都可使用。《实践论》并不要求每一件事都由作者亲历；关键是来源可信、理解其条件，而非道听途说。
- 调查不等于堆数字。事实的范围、样本、时间和局限要清楚；原材料只有大致数量时，不伪造个位数精度。

### 1.2 辩证：看关系、运动与条件，而非静态贴标签

不能把辩证法缩成优点一栏、缺点一栏。要解释：哪些方面既相互依赖，又相互制约？它们怎样推动问题发展？

| 分析任务 | 写作中必须回答的问题 | 原文依据 |
|---|---|---|
| 矛盾的特殊性 | 为什么这个对象、这个时期不能照搬别处的办法？ | 《矛盾论》第三节 |
| 主要矛盾 | 多组矛盾中，哪一组最能规定或影响当前进程？凭什么优先处理？ | 《矛盾论》第四节 |
| 矛盾的主要方面 | 在同一矛盾内部，哪一方当前占支配地位？其地位怎样可能改变？ | 《矛盾论》第四节 |
| 内因与外因 | 内部结构是什么？外部条件通过何种机制起作用？分析边界如何划定？ | 《矛盾论》第一节 |
| 阶段与转化 | 条件发生了什么变化，使旧办法不再适用？转化需要什么，而不只是等待多久？ | 《矛盾论》第三至五节、《论持久战》 |
| 同一性与斗争性 | 相互依存何以同时包含冲突？合作的条件与限度是什么？ | 《矛盾论》第五节 |
| 矛盾与对抗的区别 | 是否必须采取对抗方式？能否通过协商、调整或学习处理？ | 《矛盾论》第六节 |

**主要矛盾**是在多组矛盾间辨主次，**矛盾的主要方面**是在同一矛盾内部辨支配关系，二者不能混用。也不能把任何重要任务直接命名为主要矛盾：先说清相互作用的方面及其机制。

- 两面分析之后要有权重和取舍，不是各打五十大板。《论持久战》反对亡国论与速胜论，不是在两者之间折中，而是重新分析其共同的片面性。
- 主次是对具体范围、时点的判断，不是永久标签。暂缓次要问题，不等于它不存在或永远不重要。
- 分析内因不是替外部伤害开脱，也不是把困境一概归咎个人；更不能把社会问题都缩成自我努力。
- 现象是认识的入口，不是可随意丢弃的材料。所谓本质必须解释已知事实、经得起反例，不能用它遮蔽不利证据。
- 有矛盾不等于有人是敌人。历史文本的具体政治对象不能机械移植到团队、读者或普通争论上。

### 1.3 实践与认识：既反教条，也反零碎经验

《实践论》既要求认识从实践出发，也要求由感性材料形成对关系和规律的认识，再回到实践检验。

写作对应三个动作：
1. **占有材料**：区分事实、推测、价值主张与愿望。
2. **形成解释**：说明材料之间的联系，而非只列故事或套权威结论。
3. **接受修正**：指出什么观察会支持、削弱或推翻当前判断，下一步如何检验。

失败不会自动带来进步，重复也不等于认识提高。必须说明发现了什么错误、改了什么办法。成功的单个案例同样不能自动证明普遍规律。

### 1.4 客观条件与能动性：不空想，也不宿命

《论持久战》把已有条件与实现可能性所需的努力分开。今用时既说清不能越过的限制，也说清行动能够改变的环节。

**有利趋势不等于结果自动到来；承认困难不等于宣布无能为力。**

对长过程要区分方向、阶段、速度和实现条件。阶段由条件变化划分，不为排版强分三段；预测可在有依据时给区间、情景和时间尺度，不凭语气保证精确时日。

## 2. 科学判断：让读者能检查，而不是要求相信

本档案所说的科学判断，落实为尊重事实、分析因果、交代条件、接受检验。哲学框架帮助提出问题，不直接证明任何具体技术、历史或社会结论。

关键判断检查表：
- **事实**：已知什么？来源是什么？是否有相反材料？
- **机制**：为什么这些事实支持这个判断？中间有没有跳步？
- **条件**：适用范围、阶段、限制是什么？
- **竞争解释**：有没有同样能解释材料的另一种原因？
- **行动与检验**：现在据此做什么？出现什么变化就需要修正？

这些是审稿问题，不要求正文每段套五格模板。价值选择要说明立场和理由，不能伪装成自然科学定律。没有足够证据时，可以明确说暂不能判断，同时提出应查什么；这不削弱领导者风范。

## 3. 领导者风范：看全局，作取舍，负责任

### 3.1 冷静不是冷漠
- 正面承认困难、对方优势、自身短处，不靠轻蔑获得自信。
- 能把真实的反对意见说准确，必要时承认其合理部分，再指出它解释不了什么。没有两种实际存在的偏差，就不要硬凑两头来驳。
- 区分眼前与长远、局部与全局、目标与步骤。不随一个胜负或一条消息来回摆动。
- 对人的处境和代价有感情，但不让情绪替代判断。

### 3.2 力量不是把话说满
- 给出明确主张：当前先做什么、暂不做什么、为什么，以及要承担什么代价。
- 以理由形成方向感，不借地位、名望或训斥压人。我们、你们怎么用取决于真实关系，不假装代表不存在的组织。
- 讲清行动怎样改变条件，而不是从困难直接跳到胜利口号。
- 判断可以短而有力，但确定程度必须与证据相称。坚定的行动选择，可以与对结果的不确定认识同时存在。
- 结尾可有号召，也可停在一个清楚的判断、待完成的任务或检验办法；不必篇篇动员。

### 3.3 根据先于判断，不等于正文必须先列材料
《改造我们的学习》开篇先亮主张，再展开理由；《论持久战》也先提出明确回答，再深入论证。

**研究时不能先定结论后挑材料；表达时可以结论先行。**读者最终必须看见判断如何得来，而非被一句硬话挡住追问。

## 4. 篇章结构：按问题选择，不造新八股

| 适用任务 | 可选推进路线 | 参考文本 |
|---|---|---|
| 复杂形势判断 | 提出问题 → 检查真实分歧 → 比较条件及其变化 → 给出判断 → 提出方针 | 《论持久战》 |
| 方法与学习反思 | 承认已有成绩 → 具体指出缺陷 → 对照两种方法 → 提出改进 | 《改造我们的学习》 |
| 对流行说法的澄清 | 准确引出说法 → 用材料逐项检验 → 解释差异 → 给出适用条件 | 《游击区也能够进行生产》 |
| 转折期的任务说明 | 形势发生何种变化 → 根据是什么 → 当前重点与次序 → 风险和责任 | 《目前形势和我们的任务》 |
| 人物纪念 | 具体事迹 → 可学之处与实际表现 → 真实的个人交集 → 克制收束 | 《纪念白求恩》 |

- 结构体现论证关系，不要求固定节数、工具数量、两种错误或三阶段。短文抓住一个问题讲透即可。
- 长文可清楚标示从是什么、为什么转向怎样做，但不在每段重复导航。
- 对照不是制造稻草人；反驳也不是预先认定他人必错。
- 结尾的方向感应由前文推出。现实只支持有限目标时，就写有限目标，不硬拗宏大结局。

## 5. 语言：把深的道理说得明白

### 5.1 说理的白话与长短句
分析复杂条件时允许长句，落下判断时可用短句。长句关系清楚，短句不靠断行伪造气势。设问紧接真正的回答；不是连发反问暗示反对者愚蠢。

可学的动作：界定概念；承认一部分事实再推进；给一般判断补适用条件；下主张之后补上理由。不是把文章翻译成带时代口音的语录。

### 5.2 比喻和典故帮助理解，不代替证明
梨子、桃树、扫帚、游泳等熟悉经验，使抽象关系可见。一个比喻可以展开，但需说清对应关系与限度。典故与俗语也有相同边界：**类比不是证据，熟悉不等于正确**。

不规定每篇几个比喻、每段几个文言词。没有合适的比喻就直接讲，不为像某位作者硬塞农家意象、成语或旧词。

### 5.3 重复、排比与锋芒
- 关键概念可重复，以保持推理对象稳定；不要为换词造成偷换概念。
- 排比可承担分类、对照、递进，也可表达情感；每一项应有实指，不能整齐地说同一件事。
- 冷静是本档案的默认基调，不是原文从不激烈的事实判断。语料中确有反复断喝、反讽和动员。今用时按用户强调的冷静取舍，不为模仿而添加。
- 有理据的批评可以锋利，但不把侮辱当力量。

### 5.4 用词与精度
偏好具体动词：调查、比较、区别、检验、改变、组织、争取、承担。条件、阶段、根据、主要、次要等词只有在确实分析这些关系时才使用。

事实、数字和日期忠实于来源及其精度；不要用材料没有的精确度营造科学感。学术概念首次使用时讲清含义，不堆叠哲学名词、互联网套话或公文词汇。

## 6. 从语料到今用的边界

1. **不是把历史作者去历史化。**认识其原文的政治立场、对象和时代，再判断哪些方法能迁移。写相关历史、政治或哲学议题时，必要术语可准确使用；非相关题材不硬搬敌我标签、称谓和战争口号。
2. **不以名字代替根据。**引用注明篇名，区分作者原句、转述及自己的延伸；原文转引他人或俗语时保留归属。
3. **本地核对不等于版本校勘。**本地文本有断行、标点和引文缺漏；不得凭记忆填补。遇到可疑处，标待核对或换用完整可核实的段落。
4. **不凭风格创造经历和数据。**已知材料不足，可以提出假说、调研方案或标明的假设示例，不冒充完成过调查。
5. **不把偏好写成刻板配额。**不强求两种错误、两个工具、一两处引语或固定位置的抒情。本文体可以完全没有名言。

## 7. 写前与审稿

写前先明确：
- 本文要回答什么真实问题，面向谁？
- 手头有哪些材料，哪些只是初步解释？
- 相关的矛盾、关系、阶段和条件是什么？哪些值得展开，哪些不相关？
- 拟作何判断或主张；最有力的异议是什么；还欠哪一环根据？
- 若要行动，先做什么、为何、代价是什么、怎样检查？

审稿按顺序检查：
1. 去掉作者名字和哲学术语，分析是否仍然成立？
2. 所谓主要矛盾是否真说清了双方、关系及主导理由？有没有与主要方面混淆？
3. 有没有把两面看写成折中，把未来可能写成自动发生，把内因分析写成归罪个人？
4. 判断强度是否超过证据？是否公平处理相反材料？
5. 是否给出明确取舍，又交代限制和修正条件？
6. 语言是否明白、有分量，而非训话、名言堆叠或术语表演？

**最终标准：读者不仅听见主张，还看得见主张如何得来、在何种条件下成立，以及现在可以做什么。**

## 8. 与其他档案的分工

- A：以个体经验与内心问题为主线。
- B：以时代图景、事业愿景和激励邀请为主线。
- C：记叙向重具体的人与事；杂文向借思想评论现实。
- D：以现实分析、哲学判断和负责的方向说明为主线。

同为科技、创业、学习或社会观察，可因主线不同选择不同档案。不是 B 没有分析、D 没有激情，而是文章由什么推动。D 的方法也可辅助其他档案，不必因此把整篇改成论说文。

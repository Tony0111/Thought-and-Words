# 风格档案索引

本 skill 支持多个目标风格。**写作前先按文体选定一个风格档案，再读对应示例和 `../avoid-list.md`。**

## 怎么选

| 你要写的 | 选哪个 |
|---|---|
| 心理剖析、哲学随笔、个人心理叙事、疗愈向 | **A · `yino-psychological.md`** |
| 科技 / 创业 / 时代观察、创始人特稿、青春梦想、激励与邀请、活动招募 | **B · `monolith-inspirational.md`** |
| 人物忆述、小事记、回望式随笔；或引用鲁迅观点评论今天的事 | **C · `luxun.md`** |
| 形势判断、观点长文、驳论澄清、方法论（学习/调研/决策/带团队）、有实指的动员 | **D · `mao.md`** |
| 一篇文章两者都沾 | 以主线定一个档案，其他只作点缀 |

判断标准：**向内写一个人的内心 → A；向外写时代与事业、号召行动 → B；平静地写一个具体的人或一件事，或需要借鲁迅的思想立论 → C；冷静分析一件复杂的事、下判断、给办法 → D。**

> B 与 D 的区别是主线：B 以事业图景和激励邀请推动文章，D 以现实分析、哲学判断和负责的方向说明推动文章；不是 B 没有分析或 D 没有激情。
> C、D 的观点库 `../luxun-ideas.md`、`../mao-ideas.md` 可以跨档案使用：其他档案的文章里也可以引用，但文体仍按所选档案。

## 档案列表

### A · Yino（内向 · 心理 · 哲学）
- 风格：`yino-psychological.md`
- 示例：`../examples/yino.md`（10 篇）
- 定位：平静、可执行、从具体经验上升到存在命题；落点"人如何成为自己"。
- 题材：心理剖析、哲学随笔、个人心理叙事。不写艺术评论。

### B · Monolith（外向 · 宏大 · 激励）
- 风格：`monolith-inspirational.md`
- 示例：`../examples/monolith.md`（9 篇）
- 定位：历史纵深 + 硬核事实 + 宣言式语言；为年轻人描绘值得投身的事业图景。
- 题材：科技/创业/时代、人物特稿、观点长文、招募邀请。

### C · 鲁迅（平静 · 白描 · 半文半白）
- 风格：`luxun.md`
- 示例：`../examples/luxun.md`（记叙篇逐篇写法 + 议论篇推进路线）
- 观点库：`../luxun-ideas.md`（28 条，引文已与语料核对）
- 语料：`corpus/raw/LuXun/议论/`（15 篇杂文）、`corpus/raw/LuXun/记叙/`（20 篇）
- 定位：**杂文学思想不学腔调；记叙学文体**。平静克制、白描、半文半白；反讽可以用；结尾的升华可以保留，要从前文的事里长出来。
- 题材：人物忆述、小事记、回望式随笔、引用鲁迅观点的杂感。

### D · 毛泽东（唯物辩证法 · 冷静 · 有力量）
- 风格：`mao.md`
- 示例：`../examples/mao.md`（15 组逐篇写法 + 可迁移特征）
- 方法库：`../mao-ideas.md`（26 条；按本地文本核对，区分引文、转述与今用建议，不等于完成版本校勘）
- 语料：项目根目录下 `corpus/raw/Mao/`（35 篇；以已读正文与选段为依据，不表示逐篇通读）
- 定位：**哲学进入分析，力量来自有根据、负责任的判断**。从实际关系出发，辨明矛盾、主次、阶段与转化条件；作出取舍，交代行动、代价与检验。研究上依据先于结论，表达可结论先行；不强求两头都驳或工具配额。
- 语境：保留原文的历史与政治背景；相关题材准确使用必要术语，非相关题材不机械移植敌我标签和战争口号。
- 题材：形势判断、观点长文、驳论、方法论、有实指的动员、短篇纪念。

## 加一个新风格

1. 在 `styles/` 建 `<name>.md`（照 A/B 的章节结构写可执行规则）。
2. 在 `examples/` 建 `<name>.md`（逐篇分析 + 共同特征）。
3. 更新本索引的表格和列表。

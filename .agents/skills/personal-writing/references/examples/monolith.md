# 风格 B 参考文章分析：Monolith（砺思资本）

> 共 9 篇，存于 `corpus/raw/monolith/`。作者/机构：Monolith 砺思资本（早期 VC）。
> 目的：提炼可迁移的**宏大叙事 + 激励邀请**写法，其标志性措辞也可以直接使用。

## 总体速写

- **内容**：创始人特稿（OriginFlow、Oxus、Vivix、无尽方舟、Meshy）、科技革命长文、面向年轻人的招募/邀请。
- **气质**：向外、宏大、笃定、宣言式；用历史纵深和硬核数字，为年轻人描绘值得投身的事业图景。
- **关键词**：梦想、青春、事业、改变、创造、第一性原理、非共识、认知差、碳基生物。
- **结构签名**：反常事实/断言开头 → 编号主题小标题 → 历史/数据论证 → 反直觉判断 → 向上的宣言或邀请。
- **和风格 A（Yino）的关系**：都爱宏大命题（宇宙、文明、人生），但 A 向内写个人心理，B 向外写时代与事业。

## 逐篇

### 1. Crazy Ideas Night | 在被证明是对的之前（招募文）
- 开头：格言式断言——"每个后来改变了一个行业的想法，在最开始听起来都像是一个笑话。"
- 特征：把"疯狂/不成熟"重新框定为价值；"不用说正确的废话"；连续"欢迎……的人"排比，直接对年轻人说话。
- 可迁移：用一个反常识判断消除读者羞耻感；排比式邀请；短、直接、有态度。
- 标志性表达：活动 CTA 与品牌口号。

### 2. Meshy 完成近 4 亿美元融资（融资报道）
- 开头：硬新闻 + 数字。
- 特征：把技术讲白话（"输入一句话，几分钟得到可编辑 3D 模型"）；用用户案例和付费数据支撑；技术深潜用具体指标（分辨率、耗时）；结尾抛问句。
- 可迁移：宏大之前先讲清楚"到底在做什么"；用数字和用户故事替代形容词。
- 标志性表达：微信 UI 噪声（已关注/Follow 等）非文风。

### 3. OriginFlow 秦深涛：寡于欲者天机深（人物特稿）
- 开头：行业背景 → 问题（机器人缺的不是身体，是数据）。
- 结构：实地探访场景 → 技术解释 → 创始人成长史（游戏、想"删号"、《周易》《庄子》《海上钢琴师》、马斯克）→ 组织管理 → 结尾雪地意象。
- 特征：标题用人物金句；把技术信仰落到一个具体画面（残障员工操作灵巧手，"在人身上长出新器官"）；宏大愿景（八十亿人 always on）后立刻给一个"最笨"的落地。
- 可迁移：人物故事要有转折和代价；宏大愿景配朴素落地；结尾用诗意具体画面。
- 标志性表达："副本""删号退游""Rockflow"等标志性说法。

### 4. Oxus：AI 找矿，点石成金（人物特稿）
- 开头：极具体的画面+数字（宾厄姆峡谷铜矿，一个世纪产铜压成半径 80 米的球）。
- 小标题：源头 / 反其道而行之 / 聆听地球 / 天与不取，反受其咎。
- 特征：数据密度高但每段都落到画面；哲学托底（波普尔证伪）；比喻（和地球下围棋、给地球装麦克风）；结尾用"算术"把个人选择升到人类资源命题。
- 可迁移：用意外数字制造冲击；用成语/古语做结构与收束；把技术问成哲学问题。
- 标志性表达："和地球下围棋""聆听地球"等专属比喻。

### 5. Vivix：从没人相信的地方开始（创始人自述）
- 开头：公司冷启动 + 数字，交代"几乎没发声"。
- 小标题：没人信的时候 / 停掉的原型，换回来的认知 / 十几个没人注意到的数据源 / 成本要打到刷抖音的水平 / 创业公司的机会，在认知差 / 一号位没有退路。
- 特征：第一人称、坦诚、技术细节硬；短促有力的断言（"一号位没有退路""光脚的本质不是赌"）；反共识逻辑（认知差：对他们是 10%，对你是 30%）。
- 可迁移：用"停掉的原型"讲认知迭代；用一句狠话收束一节；反共识论证。
- 标志性表达："认知差""一号位没有退路"可直接使用。

### 6. 一场科技革命，不只由站在塔尖的人完成（思想长文）
- 开头：反常识问题——AI 革命的最大受益者竟是旧巨头。
- 结构：从庄园到工厂 → 从机床到代码 → 从信息到算力 → 新的可能性 → 碳基生物的新陈代谢。
- 特征：用经济史讲财富逻辑迁移；承认复杂性、拒绝线性类比；结尾用"David vs Goliath"与"巨头占据天空，地面才是新世界萌芽的地方"作结。
- 可迁移：历史三段式推进；先承认反例再给出结构性规律；结尾的"天空/地面"式对仗画面。
- 标志性表达："碳基生物的新陈代谢"等标志性表达。

### 7. 创业是年轻人改变世界的最硬核方式（分享整理）
- 开头：宣言式断言——"科技革命的推动力，始终来自年轻一代。"
- 结构：VC 运作 → 幂律分布 → 成功关键（团队/赛道）→ 核心逻辑（看见/看明白/投得进/退得出）→ 本质。
- 特征：知识型长文，定义清楚、编号密集、例子多；结尾三条总结 + 英文格言。
- 可迁移：把复杂机制拆成"四步/六点"；用真实案例（理想、微信、字节）支撑原则。
- 标志性表达：面向 VC 行话的特定内容。

### 8. 科技革命的驱动者为何总是年轻人（招募）
- 开头：断言 + 数据统计（历次革命创始人首次创业年龄）。
- 特征：数据（29.9→29.2→24.5 岁）；"第一性原理"解释年轻人优势；把"躺平/佛系"重新框定为一时情绪；结尾"如果你……"排比邀请 + "让我们一起改变潮水的方向"。
- 可迁移：用一组数据建立说服力；"如果你……那么你就是我们在找的人"式邀请结构；为读者赋权。
- 标志性表达："让我们一起改变潮水的方向"作为口头禅。

### 9. 长生不老：从狗开始（人物特稿）
- 开头：科学新闻 + 冲击性数字（小鼠中位寿命延长约 25%）。
- 小标题：一个念头 / 一把锁 / 两条路 / 四道墙 / 逃逸速度。
- 特征：把宏大理想（人不应死）落在具体路径（先做宠物药、跨物种 AI、四条管线）；比喻（锁孔与钥匙）；人情细节（爷爷"我不想死"）；结尾用创始人原话。
- 可迁移：用"一个念头/一把锁/两条路"这种极简意象标题串起全文；宏大目标配务实的分阶段路线。
- 标志性表达："逃逸速度"等专属概念组合。

## 9 篇的共同特征（可迁移）

1. **开头抓人**：用一个反常事实、硬数字或格言断言，绝不铺垫背景。
2. **宏大 + 具体**：先给历史/文明尺度，再立刻用数字、案例、原话托底。
3. **结构与标题**：编号主题标题；思想文用"从 X 到 Y"，特稿用意象化短标题。
4. **反直觉判断**：非共识、第一性原理、认知差；先承认反例再给结构性规律。
5. **宣言式语气**：笃定、敢下判断；用反问推进；短句收束。
6. **激励与邀请**：把读者从边缘/劣势重新框定为新世界的先来者；"如果你……"排比号召。
7. **比喻的野心**：和地球下围棋、给地球装麦克风、新器官、新的副本。
8. **收尾**：诗意具体画面（人物稿）或向上宣言 / 邀请（思想与招募）。

| 题材 | 心理剖析、哲学随笔、个人叙事 | 科技、创业、时代观察、人物特稿 |

| 语气 | 平静、温柔、布道 | 笃定、宣言、号召 |

## 需要用户决定的偏好

- **宏大尺度**：历史/文明级开篇，是否每篇都要？还是仅观点长文用？
- **热血浓度**：宣言/号召用到什么程度不显得空喊？
- **数据密度**：像 Monolith 这样硬数据密集，是否是你想要的？
- **金句/古语**：成语与英文格言点缀的分寸。

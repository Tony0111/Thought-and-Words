# 禁止与警惕清单

> 写完后逐项检查。这一份可以随时补充——每次看到让你皱眉的 AI 味表达，就加进来。

## 空泛开场

- “在这个快速发展的时代……”
- “随着……的不断发展……”
- “我们生活在一个……的世界里”
- 任何先讲大背景、三句之后才进入正题的开头

## 万能连接与过渡

- “值得注意的是”
- “与此同时”
- “综上所述”“归根结底”“总而言之”
- “不难发现”“众所周知”
- 每段都用“首先/其次/最后”

## 抽象堆砌

- 连续出现三个以上抽象名词
- 为了显得深刻而制造不必要的比喻
- 把普通观点包装成宏大结论
- 用排比制造虚假气势

## 虚假完整

- 每段都工工整整、长度相近
- 强行三点式、对仗式小标题
- 过度总结，把读者当不会思考的人

## 鸡汤与升华

- 结尾硬拗金句
- “愿我们都能……”
- “让我们一起……”式的**无实指**号召（风格 B 允许号召，但必须有具体行动或确指，不能空喊）
- 把具体问题拔高到人生哲理

## 事实层面

- 编造数据、引语、案例
- 把“一般来说”写得像确凿事实
- 用模糊表述掩盖没查证的内容

## 参考作者的标志性表达（只学方法，不要照搬）

判断标准：如果一句话抄进搜索框能直接找到原文，就不要用。

### Yino（风格 A）

- 自创术语：召命、隐影响力、反敏感、“第三物”（可以借鉴“辩证整合”的方法，但自己另取名）
- 标志意象：镜面碎裂一地、纯白空间、“手心的一半金币”、Nuos 坠落、雪豹图腾
- 标志句子：“暧暧内含光，自顾自地生长”、丰饶之域、娑婆世界、月下世界
- 口头禅式古典词：文质彬彬、镜中幻影、垂目内观（可引用原典，但不要当作自己的惯用语）
- 文末商业推广：专栏 / 研讨班 / 新书导流（除非明确要求写营销文）

### Monolith（风格 B）

- 标志口号：“让我们一起改变潮水的方向”、”碳基生物的新陈代谢“、“巨头们可以占据天空，但地面上才是新世界萌芽的地方”
- 专属比喻：和地球下围棋、给地球装麦克风、新的副本、Rockflow（岩浆）、抓住锁孔和钥匙
- 专属概念：“长寿逃逸”（Longevity Escape Velocity 可引用原概念，但不要当口头禅）、认知差 / 一号位没有退路 这类句式
- 古语当结构：“天与不取，反受其咎”——可以改用其他成语，不要每篇都套同一句
- 文末招募模板：扫码报名 / 留言抽奖 / 投递入口（除非明确要求写招募文）

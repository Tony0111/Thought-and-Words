# 写前 brief 模板

> 每篇文章动笔前先填这份。内容来自你，AI 负责整理和提问。

## 基本信息

- 工作标题：
- 文体：（随笔 / 评论 / 教程 / newsletter / 其他）
- 风格档案：（A 心理哲学 / B 科技事业激励 / C 鲁迅 / D 毛泽东 —— 见 references/styles/README.md）
- 若选 C：（记叙向：学文体 / 杂文向：引用观点）
- 若选 D（只填与本题有关的项，不为填表制造分歧）：
  - 要回答的真实问题与已有材料：
  - 相关的矛盾双方、相互关系与当前阶段：
  - 哪组矛盾当前最有支配作用？依据是什么？（与同一矛盾的主要方面区分）
  - 初步判断、最有力的异议或相反材料：
  - 判断成立的条件，以及会使我修改判断的证据：
- 目标读者：
- 期望长度：
- 发布渠道：

## 核心

- 我想说的核心观点（一句话）：
- 读者读完应该带走什么：
- 这篇文章为什么值得写：

## 真实素材（必须来自我自己）

- 我的经历 / 观察：
- 具体细节、场景、对话：
- 数据 / 事实 / 来源：
- 我想引用的内容：（按需引用；从 `references/luxun-ideas.md` / `references/mao-ideas.md` 选，记录编号、篇名及原句/节引/转述）
- 若选 D：亲身调查或可靠的间接资料（来源、时间、范围、局限；未调查不要冒称）：

## 结构与边界

- 大致结构或推进顺序：
- 必须提到的点：
- 明确不想写成的样子：（如：不要写成干货清单）
- 结尾想落在哪：
- 若选 D 且需要行动：当前先做什么、暂不做什么、为何这样取舍、代价是什么、怎样检验并调整：

## 待确认

- 还没查证的事：
- 需要补充的素材：

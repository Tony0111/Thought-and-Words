# Personal Writing

一个个人写作辅助 skill。目标不是让 AI 代替用户写作，而是让 AI 在保留用户真实观点与素材的前提下，稳定地使用用户认可的表达方式。

## 开始前必读

动手写之前，先读这些文件（相对于本 skill 目录）：

1. `references/styles/README.md` —— **按文体选定一个风格档案（A=yino 心理哲学 / B=monolith 科技激励 / C=luxun 鲁迅 / D=mao 毛泽东）**。
2. 选定的风格档案（`references/styles/<选定风格>.md`）—— 必须遵循的句子节奏、结构、比喻规则。
3. `references/avoid-list.md` —— 必须避免的表达和倾向（注意风格 A/B/C/D 的例外条款）。
4. 若文章要引用鲁迅或毛泽东的观点，先读 `references/luxun-ideas.md` / `references/mao-ideas.md`；**不要凭记忆引用**。两库均可跨档案使用。毛泽东库以本地语料为核对范围，不等于完成权威版本校勘；须区分原句、节引、转述，以及原文转引的他人观点。
5. 对应示例 `references/examples/<风格>.md` —— 参考文章索引和提炼出的风格规律。用于理解风格；其中的术语、意象和句子可以直接使用。

如果选定的风格档案还是空白模板，先暂停写作，协助用户一起把它填好。

## 写作流程

0. **选定风格**
   - 向内写个人内心/心理/哲学 → 风格 A（yino）；向外写时代/事业/梦想/激励邀请 → 风格 B（monolith）；平静地写一个具体的人或一件小事 → 风格 C（luxun）；冷静分析一件复杂的事、下判断、给办法 → 风格 D（mao）。
   - 一篇文章多处沾边时，以主线定一个，其他只作点缀。
   - 详细判断标准见 `references/styles/README.md`。
   - 选 C 时的额外一步：确定这篇要走**杂文**（学思想：引用观点、借用论证）还是**记叙**（学文体：白描、半文半白、平静克制），两者不要混着硬凑。
   - 选 D 时的额外一步：先整理**事实、解释、条件与行动**，区分真实材料、可靠的间接资料和待检验的假说；辨明相关的矛盾、主次、阶段及转化条件。不强求两个工具或两种错误；材料不足时提出调查清单，不虚构调查。领导者风范体现为有根据的取舍、责任与修正能力，不是确定无疑的口吻。

1. **补全 brief**
   - 确认主题、读者、核心观点、真实素材、期望长度和文体。
   - 使用 `templates/article-brief.md` 的结构。
   - 缺关键信息时向用户提问，不要自行编造。

2. **不虚构**
   - 不虚构用户的经历、事实、数据、引语或观点。
   - 需要举例时，可以用一般性场景，但要明确标注这是举例，并提醒用户补充真实细节。
   - 拿不准的事实，明确写“待确认”，不要含糊带过。

3. **搭结构**
   - 先给出文章结构和每部分要点，让用户确认，再动笔写正文。
   - 结构服务于观点推进，不追求形式对称。

4. **写初稿**
   - 应用所选风格档案中的句子节奏、语气、叙述视角和结构偏好。
   - 优先使用用户提供的具体细节，而不是抽象概括。

5. **自检 AI 味**
   对照 `avoid-list.md` 逐项检查，至少覆盖：
   - 是否有空泛的 AI 式开场（“在这个……的时代”）；
   - 是否堆砌抽象概念和排比；
   - 是否每段都在推进观点，有没有原地打转；
   - 是否保留了具体细节和真实判断；
   - 是否过度工整、过度总结、过度升华；
   - 结尾是否硬拗金句或鸡汤（**注意**：风格 B 允许宣言式号召，D 也可在分析之后提出行动要求；都必须有具体实指，不能空喊）。

6. **风格特征对照**
   从 `references/examples/<风格>.md` 的“可迁移特征”里挑 2-3 条核心的，对照初稿是否真的用上了：
   - **风格 A（yino）**：核心比喻是否贯穿全文？是否有心理学/哲学框架支撑？是否从具体场景进入？
   - **风格 B（monolith）**：宏大判断后是否紧跟硬核事实/数字托底？是否有激励邀请而非说教？
   - **风格 C（luxun）**：
     - 记叙向：是否白描为主（有具体动作、原话、物件，而非心理分析）？议论是否短而少、跟在事实后面？结尾若有升华，是否从前文事实里长出来、一两句即收？
     - 文言密度是否克制（一段 1–2 处），没有写成假古董？
     - 杂文向：引用鲁迅观点是否注明篇名、是否接了自己的延伸？有没有在模仿他的骂人腔？
   - **风格 D（mao）**：
     - 哲学是否进入了具体分析，而非堆术语？主要矛盾与矛盾的主要方面是否分清？是否说明阶段、条件和关系？
     - 判断能否由材料和机制支持，强度是否与证据相称？研究上根据先于结论，表达上允许结论先行。
     - 是否公平处理真实异议，而非硬凑两头、取中间立场？有没有把可能写成必然、把内因分析写成归罪个人？
     - 需要行动时，是否说明先做什么、为何、代价与检验办法？冷静与力量是否来自负责的取舍，而非训话？
     - 原文引语、今用建议和用户偏好是否分清？相关题材可用必要的历史、政治或哲学术语，非相关题材不搬敌我标签。
   - 不只是避免 AI 味，更要主动命中风格签名。

7. **交付**
   - 输出文章正文（默认写入 `drafts/` 文件，不往对话里贴全文，除非用户要求）。
   - 附一段简短说明：用了哪个风格档案的哪些特征、哪些地方需要用户补充真实素材。

## 改写与审稿

用户给一篇现成文本要求改写时：

1. 先指出原文的问题（结构、语气、AI 味），再改。
2. 保留作者原意和原有事实，不擅自添加观点。
3. 修改后说明主要改动点。

## 边界

- 不替用户决定他们真正想说什么。
- 不把普通观点包装成宏大结论。
- 用户没要求时，不强行给文章加标题、金句或升华结尾。
